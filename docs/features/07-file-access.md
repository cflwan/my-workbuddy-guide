# 文件访问

## WorkBuddy 怎么访问你的文件

WorkBuddy 默认不能乱翻你电脑里的文件。它要读要写，得你点头。

具体流程大概这样：

1. 对话里你让它处理某个文件（"帮我改一下桌面的 report.docx"）
2. 它会请求访问权限
3. 你授权（通常是弹个确认）
4. 它才能读那个文件
5. 写操作也是类似，要单独授权

不是"给了权限就能翻全家桶"。每次操作具体文件，权限是跟着操作走的。

## 授权流程

**读文件**

它要读，会告诉你读哪个、为啥读。你同意了它才读。

**写文件**

写比读更谨慎。它会明确告诉你：
- 要写哪个文件
- 会覆盖还是新建
- 写啥内容

你确认了才动手。

**批量操作**

如果你让它处理一堆文件（"把这目录下所有图片重命名"），它会先列出要动的文件清单，你过目同意了再批量执行。

::: tip 看清楚再点同意
授权弹窗别秒点"同意"。看一眼它要干啥，尤其是写操作和删除操作。
:::

## 安全边界

**能做的：**
- 读你授权的具体文件
- 在你授权的位置写文件
- 在指定目录内做文件操作
- 创建、编辑、重命名（你授权后）

**不能做的：**
- 翻你没授权的目录
- 操作系统关键文件
- 静默删除（删除必会先告知）
- 把你的文件偷偷传到外部（除非你明确让它上传）
- 越权访问（授权了 A 文件，不会顺手去读 B 文件）

## 哪些操作要格外留意

**删除操作**：最危险。它会先告诉你要删啥，但删了就没了（不一定进回收站）。删之前最好备份。

**覆盖写**：它要写一个已存在的文件，会提示"这会覆盖原内容"。原内容就没了。重要文件先备份。

**批量重命名/移动**：一次动很多文件，万一逻辑错了就是批量灾难。让它先 dry-run（只列出会怎么改，不真改），你确认了再执行。

**路径写错**：它可能把文件写到错误位置。授权前看清它说的路径对不对。

## 怎么组织文件更好用

**项目分目录**：一个项目一个文件夹，别一堆项目的文件混在一起。WorkBuddy 处理起来也更清晰，授权也更精准。

**别把敏感文件放工作目录**：密码本、证件扫描件、合同原件这种，别放在你让 AI 频繁操作的目录下。

**用清晰的命名**：`2024年Q3销售报告.docx` 比 `新建文档1.docx` 强太多。AI 也能更准确识别要操作哪个文件。

**定期清理**：工作目录里堆一堆旧文件，授权时容易搞混。定期把用完的归档或删掉。

## 一个实用场景

你说："帮我把桌面 report 文件夹里所有 docx 转成 pdf"

它会：1）请求访问桌面 report 文件夹 2）列出所有 docx 3）告诉你打算怎么转 4）你确认后执行 5）告诉你结果。整个过程你能看到它要干啥，随时能喊停。

## 我的建议

::: tip 授权最小化
每次只授权它当下需要的文件。别图省事一次性给一大堆权限。
:::
