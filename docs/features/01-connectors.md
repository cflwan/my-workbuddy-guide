# 连接器（Connectors）

## 啥是连接器

连接器就是让 WorkBuddy 能对接外部应用的桥梁。

比如：
- 连接 GitHub，让 WorkBuddy 能操作你的仓库
- 连接飞书，让它能读写飞书文档
- 连接企业微信，让它能发消息
- 连接腾讯文档，让它能操作在线文档

## 有哪些连接器

::: tip 官方为准
连接器列表会持续更新，以 WorkBuddy 应用内的连接器管理页面为准。
:::

常见的有：
- GitHub - 代码仓库
- 飞书 - 协作办公
- 企业微信 - 即时通讯
- 腾讯文档 - 在线文档
- 钉钉 - 办公协同
- Notion - 知识管理
- 各种金融数据平台

## 怎么连

1. 在 WorkBuddy 右上角找到连接器管理
2. 找到你想连的服务
3. 点"连接"
4. 跳转到该服务的授权页面
5. 授权完成，WorkBuddy 就能操作它了

## 连了能干啥

以 GitHub 为例：
- 读取仓库代码
- 创建分支
- 提交代码
- 查看 PR
- 修复 CI 失败

以飞书为例：
- 读取多维表格数据
- 写回飞书文档
- 处理协作数据

## 我的建议

::: tip 按需连
别全连上。用到哪个连哪个，连了不用的反而增加安全风险。
:::
