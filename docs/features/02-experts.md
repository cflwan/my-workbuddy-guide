# 专家（Experts）

## 啥是专家

简单说，专家就是给 WorkBuddy 套上一层"职业身份"的配置包。

默认状态下，WorkBuddy 是个啥都懂一点的通才。但你让它写一份法律合同，它可能写得不够专业；让它做财务分析，可能术语用得不太对。

专家包就是来解决这个问题的。它内置了某个领域的专业知识、常用工具、说话风格、甚至一些行业黑话。一旦挂上专家，WorkBuddy 立刻变身那个领域的行家。

## 怎么选专家

在对话界面里能找到专家选择入口。点开会看到一个专家列表，挑一个你需要的就行。

切换很方便，随时能换。做不同任务可以挂不同专家。

::: tip 别死磕一个专家
写代码挂程序员专家，写文案挂营销专家，别一个专家用到底。
:::

## 常见的专家类型

目前能见到的专家大概分这几类：

- **金融类** - 懂财报、懂估值、懂股票基金，适合投资分析、研报撰写
- **法律类** - 懂合同审查、合规风险、法律条款解读
- **HR 类** - 懂招聘、薪酬、绩效、员工关系
- **营销类** - 懂文案、品牌、投放、用户增长
- **设计类** - 懂 UI/UX、视觉规范、设计稿评审
- **研发类** - 懂代码架构、技术选型、工程实践
- **产品类** - 懂需求文档、PRD、用户研究

具体名单会更新，以应用内看到的为准。

## 啥时候该用专家

建议这几个场景必挂：

1. **写专业文档** - 合同、研报、PRD 这种需要行业术语的
2. **做专业判断** - 给一段代码做架构评审、给一份合同挑风险点
3. **用专业工具** - 比如金融专家会用金融数据接口，普通模式不会
4. **跑专业流程** - 比如 HR 专家知道招聘流程长啥样

日常聊天、随便问个问题，不挂专家也行。

## 怎么用得更好

几个实战小技巧：

**技巧一：任务匹配专家**

写文案别挂程序员专家，写代码别挂营销专家。听起来废话，但真有人这么干。

**技巧二：组合用**

一个任务可以先后挂不同专家。比如先挂产品专家写 PRD，再挂设计专家出 UI 建议。

**技巧三：看专家说明**

每个专家包都有介绍，点开看看它擅长啥、不擅长啥。别指望一个专家包打天下。

**技巧四：专家不是万能的**

挂了专家不代表输出一定对。专业领域的关键结论，还是得你自己复核。

## 专家和连接器的区别

这俩容易混。

- 专家 = 给 WorkBuddy 加"脑子"，让它懂某个领域
- 连接器 = 给 WorkBuddy 加"手"，让它能操作某个外部应用

专家让它更懂法律，连接器让它能操作你的飞书。两个可以同时用。

## 我的建议

::: tip 按任务挂专家
别默认挂一个专家从头用到尾。任务变了就换，没合适专家就空着。
:::

如果你经常做某类工作，比如天天写研报，那挂上金融专家确实省事。偶尔用一次的任务，用到时再挂也来得及。
