# 记忆系统

## 为啥需要记忆

AI 默认是"金鱼脑"，每次对话都从零开始。你上周说"我用的是 React 18"，这周它又忘了，又问你一遍。

记忆系统就是解决这个的。把你的偏好、习惯、项目背景存下来，下次对话直接用上，不用每次重新介绍自己。

## 三层记忆

WorkBuddy 的记忆分三层，作用不一样。

### 第一层：云端档案（cloud profile）

存在云端，跟你账号走。换电脑、换设备都能用。

适合存：
- 你的职业身份（"我是前端开发"）
- 长期偏好（"喜欢简洁的代码风格""不爱看废话"）
- 通用习惯（"回复用中文"）

这是最稳定的一层，跨设备跨会话都在。

### 第二层：用户级记忆（~/.workbuddy/MEMORY.md）

是个本地文件，在你电脑上。这个文件里写的所有内容，WorkBuddy 每次启动都会读到。

适合存：
- 本机环境信息（"我用的是 macOS，Node 版本 20"）
- 本地常用路径（"项目都在 ~/Projects 下"）
- 本地偏好（"代码提交信息用英文"）

和云端档案的区别：这个是本机的，换了电脑看不到。适合存跟这台机器相关的东西。

### 第三层：工作区记忆（workspace memory）

跟着具体项目走。每个工作区有自己的记忆文件。

适合存：
- 这个项目的背景（"这是给客户 A 做的电商项目"）
- 项目约定（"用 Tailwind，不用手写 CSS"）
- 当前进度（"登录模块做完了，正在做支付"）

换项目时这套记忆不跟着你，互不干扰。

## 啥时候用哪层

简单判断：

- **换电脑也想保留** → 云端档案
- **只跟这台电脑有关** → 用户级 MEMORY.md
- **只跟这个项目有关** → 工作区记忆

## 怎么写入记忆

**方法一：直接说**

对话时告诉它："记住我用的是 Vue 3"。它会判断这条信息该存哪层，自动帮你存。

**方法二：手动编辑文件**

MEMORY.md 就是个普通 markdown 文件，直接用编辑器打开改就行。工作区记忆文件同理。手动改的好处：能精确控制写啥、咋组织。

**方法三：让它主动问**

你可以说："开始干这个项目前，先问问我需要记啥"。它会引导你提供关键信息并存好。

## 写好记忆的小技巧

**写具体，别写虚的**：差：`我喜欢好的代码`；好：`代码风格用 4 空格缩进，函数名用驼峰，注释用中文`。

**分门别类**：MEMORY.md 里别一坨糊一起。用标题分：

```
## 环境
- macOS, Node 20

## 代码偏好
- 4 空格缩进
- 函数式风格

## 常用路径
- 项目：~/Projects
- 文档：~/Docs
```

**定期清理**：偏好变了、项目结束了，就把过期的记忆删掉。一堆陈旧信息反而会误导 AI。

**别存敏感信息**：密码、token、密钥这种别往记忆里塞。记忆文件不一定加密，泄露了麻烦。

## 我的建议

::: tip 先把基础打好
先把云端档案和 MEMORY.md 里关于你自己和环境的部分填好。这俩最常用，填一次受益很久。
:::
