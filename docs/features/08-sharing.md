# 分享功能

## 啥是分享

你用 WorkBuddy 做出了一份报告、一份 PPT、一段代码，想给别人看。分享功能就是把这些成果发出去。

不用再"做完 -> 下载到本地 -> 找个网盘传上去 -> 发链接"这一套。直接在对话里就能分享出去。

## 能分享到哪

支持几个常见去处：

**腾讯文档**

传到腾讯文档，变成在线文档。对方不用装 WorkBuddy，打开链接就能看、能评、能协同编辑。

适合：文字报告、表格、需要协作的文档。

**网盘**

传到你的网盘（比如夸克网盘），生成下载链接。

适合：大文件、视频、压缩包这种不适合在线看的。

**ima 知识库**

传到 ima 知识库，作为知识沉淀下来。

适合：团队知识管理、长期沉淀的资料。

**乐享**

传到乐享这种内部协作平台。

适合：团队内部分享、让同事看到你的产出。

::: tip 看场景选
要协作改就传腾讯文档，要给人下载就传网盘，要沉淀知识就传 ima。
:::

## 怎么分享

**方法一：直接说**

对话里说："把这个报告分享到腾讯文档"或"生成一个分享链接"。

它会：1）确认要分享的内容 2）让你选分享到哪 3）上传 4）给你一个链接。

**方法二：用按钮**

生成的文件旁边通常有"分享"按钮，点一下选目的地。

## 公开链接

分享后会生成一个链接。这个链接可以是：

- **公开的** - 谁有链接都能看
- **限定访问** - 只对特定人开放，可能要登录、要密码
- **可编辑/只读** - 你设对方能不能改

具体支持哪些权限组合，看分享到的平台。腾讯文档有完整权限体系，网盘一般就是"能看/能下载"。

::: tip 敏感内容看权限
公司内部资料别设公开链接。设限定访问，或者只发给指定的人。
:::

## 几个实用场景

**给客户发报告**：做完直接说"分享到腾讯文档，设成只读"，拿到链接发给客户，对方打开就能看。

**团队协作改 PPT**：分享到腾讯文档设可编辑，发到团队群里让大家一起改。

**沉淀知识库**：传到 ima 知识库，以后团队谁要查都能找到。

**给老板看进度**：生成一个公开链接，发到群里让相关人都能点开看。

## 分享权限要注意

**注意一：默认权限**

分享时看清楚默认是公开还是私密。有些平台默认公开，一不小心就全网可见了。

**注意二：链接泄露**

链接一旦发出去就收不回了（除非你主动取消分享）。发之前想清楚给谁、对方会不会转发。

**注意三：内容敏感性**

公司机密、客户隐私这种，别往公开渠道发。宁可麻烦点用限定访问。

## 我的建议

::: tip 分享前先过一遍内容
别做完就秒发。先自己看一遍有没有敏感信息、错别字、没改完的草稿痕迹。
:::
