# 参考手册

这里有 WorkBuddy 官方文档的入口，需要查权威资料的时候来这。

实战教程在 [案例库](../recipes/00-index.md)，这里是查参数、
看能力边界、找官方说明的地方。

## 官方主站

- **[workbuddy.cn](https://workbuddy.cn)** — WorkBuddy 官网，
  有产品介绍、定价、最新动态、博客。想知道 WorkBuddy 最新加
  了啥能力、政策有没有变化，看这里。

## 怎么用这些链接

**查能力边界：** 用 WorkBuddy 之前先看 Overview，知道它
能干啥不能干啥，避免派活派错地方。

**学正确姿势：** Quickstart 和 Create-Task 教你怎么描述任务。
描述任务的方式直接决定产出质量，值得花 5 分钟看。

**遇到问题：** 任务卡住、结果不对，先看 Task-Management
和 Results，里面讲了怎么跟进、怎么查看中间状态、怎么重新跑。

**想看一手资料：** 官方文档永远是最新最准的。本指南只是
帮你把官方能力翻译成「大白话」和「实战场景」，真要查参数、
查 API、查限制，还是看官方的。

## 这份指南和官方文档啥关系

- **官方文档**：权威、完整、更新及时，但是偏说明性
- **本指南**：大白话 + 实战场景，帮你快速上手和理解，
  但不替代官方文档的完整性

建议：先看本指南的 [快速上手](../guide/00-index.md)
和 [案例库](../recipes/00-index.md) 建立直觉，
具体能力边界和参数查官方文档。
