## 这是什么？

WorkBuddy 是腾讯出的一个 AI 办公工作台。跟普通 AI 聊天不同，它能真的动手干活：帮你写文档、做表格、做 PPT、分析数据、写代码、整理文件。

官方文档写得太"官方"了，读起来费劲，所以我自己用大白话整理了一遍。

## 跟普通 AI 聊天有啥不一样

| 普通 AI 聊天 | WorkBuddy |
| --- | --- |
| 只能聊天，给建议 | 能实际执行任务 |
| 你得自己操作文件 | 自动操作本地文件 |
| 单步骤简单任务 | 多步骤复杂任务 |
| 输出文字回复 | 交付可验收的结果（文档、表格、PPT） |
