# 查看结果

## 右侧结果区

WorkBuddy 干活的时候，右边会实时显示结果。四个标签页：

### 1. 产物

任务生成的文件和交付物：
- Word 文档
- Excel 表格
- PPT 演示文稿
- 分析报告
- 代码文件

点文件可以预览。右上角有分享按钮，可以上传到云端或生成分享链接。

### 2. 浏览器

如果生成的是网页或应用，可以在这里直接预览：
- 页面地址
- 刷新按钮
- 实时查看效果

### 3. 变更

显示这次任务改了哪些文件：
- 修改的文件列表
- 每个文件的改动详情
- 适合检查代码类任务

### 4. 工作空间文件

当前工作空间里的所有文件：
- 左边文件树
- 右边文件内容
- 检查文件是否写到了正确位置

## 产物分享

点产物文件右上角的分享图标：
- 上传到我的云端网盘
- 上传到腾讯文档
- 上传到 ima 知识库
- 上传到乐享知识库
- 生成公开分享链接

## 验证建议

::: tip 检查三步
1. 看产物：文件内容对不对
2. 看变更：改了哪些文件
3. 用浏览器预览：如果是网页看效果
:::
