# 对话和追问

## 任务不是一次性的

创建任务后，你可以一直跟 WorkBuddy 对话，让它调整、扩展、修改。

## 能发什么

- **文字**：直接打字
- **截图**：`Cmd/Ctrl + V` 粘贴
- **文件**：拖拽或点上传按钮
- **代码**：直接粘贴代码片段

## 支持的文件类型

PDF、Word、TXT、Markdown、Excel、CSV、PPT、常见图片、ZIP 压缩包、代码文件等。

## 追问示例

任务完成后，继续说：

| 场景 | 你说啥 |
| --- | --- |
| 调整内容 | "表格按销售额排序" |
| 补充内容 | "再加一个饼图" |
| 修改格式 | "把字体调大一点" |
| 导出 | "帮我导出成 PDF" |
| 深入分析 | "再分析一下环比变化" |
| 修复 | "第三页的数据不对，重新算一下" |

## 中断和继续

任务正在跑的时候，可以点停止按钮中断它。

中断后不用重新开始，继续打字发送就行，它会接着之前的上下文。

## 隐私保护

::: tip 你的数据是安全的
- 文件处理默认在本地完成
- 服务端只处理数据片段，用完就扔
- 不保存也不用于训练
- 只能访问你主动授权的文件夹
:::
