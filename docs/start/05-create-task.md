# 创建任务

## 核心：一句话说清楚

WorkBuddy 最强的能力是理解自然语言。你不需要学什么特殊语法，直接用人话说就行。

## 好任务的四个要素

### 1. 目标：干啥

❌ "帮我搞一下那个文档"
✅ "帮我写一份本周工作周报，包含完成的工作、遇到的问题和下周计划"

### 2. 输入：有啥

告诉它你有什么素材：
- "根据这份销售数据 Excel..."
- "根据这份会议纪要..."
- "参考这个产品介绍..."

### 3. 输出：要什么格式

- "输出为 Word 文档"
- "生成 PPT 演示文稿"
- "生成 Excel 表格"
- "写一个 HTML 网页"

### 4. 约束：有啥要求

- "字数控制在 500 字以内"
- "用中文"
- "风格正式一些"
- "包含图表"

## 完整示例

```
帮我根据这份销售数据生成分析报告：
- 数据文件：已上传的 sales_2024.xlsx
- 分析维度：按月度统计销售额、订单量、客单价
- 输出格式：Word 文档
- 包含柱状图和趋势折线图
- 风格：正式商务报告
- 末尾附上改进建议
```

## 选工作空间

点输入框左下角的"选择工作空间"，指定一个文件夹。WorkBuddy 会在那个文件夹里读文件、写结果。

不选也行，它用默认目录。

## 添加上下文

| 方式 | 说明 |
| --- | --- |
| `@` 引用 | 引用文件、文档、规则 |
| 粘贴截图 | `Cmd/Ctrl + V` |
| 上传文件 | 点上传按钮或拖拽 |
| 补充说明 | 在任务描述里写清楚 |
