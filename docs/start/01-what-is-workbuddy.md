# WorkBuddy 是什么

## 一句话版本

WorkBuddy 是腾讯出的 AI 办公工作台，你说一句话，它帮你把活干了。

## 多说几句

你用过 ChatGPT、文心一言这些 AI 聊天吧？它们能聊天、能回答问题，但干不了活——你让它帮你写个报告，它给你一段文字，你还得自己复制粘贴到 Word 里排版。

WorkBuddy 不一样，它能**真的动手**：

- 你说"帮我根据这份销售数据生成分析报告"，它真的给你生成一个 Word 文件
- 你说"整理 Downloads 里的图片按日期分类"，它真的去操作你的文件夹
- 你说"做个 PPT 介绍这个产品"，它真的给你生成一个 PPT 文件
- 你说"帮我写个网站"，它真的给你写代码、建文件

## 它能干啥

| 场景 | 具体能力 |
| --- | --- |
| 文档 | 写报告、技术文档、会议纪要、README |
| 表格 | 数据分析、可视化、Excel 处理 |
| PPT | 从需求描述生成演示文稿 |
| 代码 | 写代码、修 bug、重构、代码审查 |
| 设计 | 界面设计、Logo、海报、交互原型 |
| 研究 | 深度调研、文献整理、行业报告 |
| 文件 | 批量整理、重命名、格式转换 |
| 邮件 | 编辑邮件、写周报 |

## 跟传统 AI 的区别

| 普通 AI 聊天 | WorkBuddy |
| --- | --- |
| 只能聊天，给建议 | 能实际执行任务 |
| 你得自己操作文件 | 自动操作本地文件 |
| 单步骤简单任务 | 多步骤复杂任务 |
| 输出文字回复 | 交付可验收的结果 |

## 它不是什么

- 不是万能的，会犯错，你得检查
- 不是全自动的，你得告诉它干啥
- 不是免费的，需要账号和网络
