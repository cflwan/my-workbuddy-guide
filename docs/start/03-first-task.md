# 跑第一个任务

## 别想太多，先跑通

咱们来个最简单的：让 WorkBuddy 帮你写一份周报。

## 操作步骤

1. 打开 WorkBuddy
2. 在对话区输入框里打字：

```
帮我写一份本周工作周报，要求：
- 标题：本周工作总结
- 分三个部分：本周完成的工作、遇到的问题、下周计划
- 每个部分列 3-5 条要点
- 输出为 Word 文档
```

3. 按回车或点发送

## 会发生什么

WorkBuddy 会：
1. 理解你的需求
2. 自动规划执行步骤
3. 在对话区展示执行过程（你会看到"正在思考"、"正在生成"等）
4. 在右侧结果区生成 Word 文件
5. 完成后告诉你结果在哪

## 验证结果

1. 看右侧结果区的"产物"
2. 点击生成的 Word 文件预览
3. 确认内容是否符合预期

如果满意，可以下载到本地。
如果不满意，继续对话说"xxx 改一下"。

## 第二个任务：试试数据分析

在输入框里说：

```
我有一份销售数据 Excel 文件，帮我分析一下月度趋势，生成一个带图表的分析报告。
```

然后上传你的 Excel 文件（拖拽到输入框或点上传按钮）。

## 你刚学到了什么

- 怎么给 WorkBuddy 下任务
- 怎么看执行过程
- 怎么查看结果
- 怎么让它修改

这就是 WorkBuddy 的基本工作流程：**描述 -> 执行 -> 查看 -> 修改**。
