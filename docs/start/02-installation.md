# 下载安装

## 去哪下

::: tip 官方为准
下载地址以 [WorkBuddy 官网](https://www.workbuddy.cn/) 为准。
:::

去 WorkBuddy 官网下载对应系统的安装包。

## 环境要求

- macOS 或 Windows 系统
- 需要网络连接
- 需要注册登录 WorkBuddy 账号

## Mac 安装

1. 下载 `.dmg` 文件
2. 双击打开，拖到 Applications
3. 打开 Applications，双击启动

## Windows 安装

1. 下载 `.exe` 安装包
2. 双击运行，跟着向导走
3. 从开始菜单启动

## 第一次打开

1. 会让你登录，用微信扫码或手机号登录
2. 登录后进入主界面
3. 左边是任务列表，中间是对话区，右边是结果区
