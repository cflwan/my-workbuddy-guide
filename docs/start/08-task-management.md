# 任务管理

## 任务列表

左边侧边栏显示你的所有任务，分两个板块：

- **任务**：最近访问或更新的任务
- **空间**：按工作空间分组，同一个项目下的任务集中看

## 搜索和筛选

- **搜索**：按任务标题找
- **筛选**：按状态（进行中、已完成、失败等）或日期筛选

## 任务状态

| 状态 | 意思 |
| --- | --- |
| 进行中 | 正在干活 |
| 已完成 | 干完了 |
| 失败 | 出错了 |
| 待处理 | 等你输入 |
| 规划中 | 正在想怎么干 |
| 已归档 | 收起来了，以后能看 |

## 能干啥

### 对单个任务

| 操作 | 干啥 |
| --- | --- |
| 置顶 | 放到列表最上面 |
| 打开文件夹 | 打开任务所在的工作目录 |
| 重命名 | 改任务名 |
| 保存到工作空间 | 持久保存，可开多 Agent 协作 |
| 分享任务 | 生成公开链接 |
| 删除 | 删掉 |
| 归档 | 收起来，在系统设置里能看 |

### 对工作空间

| 操作 | 干啥 |
| --- | --- |
| 新建任务 | 在同一空间开新任务 |
| 打开文件夹 | 打开工作目录 |
| 从列表中移除 | 移除工作空间 |

## 继续已有任务

不管任务是完成了、失败了、还是中断了，都可以重新进去继续发消息，接着之前的上下文推进。

适合的场景：
- 结果不够完整，想继续细化
- 失败了，补充信息再试
- 想在之前结果上扩展新需求
