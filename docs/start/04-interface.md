# 认识界面

## 三大区域

打开 WorkBuddy，你看到三个主要区域：

### 1. 侧边栏（左边）

- 任务列表，按文件夹分组
- 顶部有搜索框，能搜任务
- 底部是你的头像和设置

### 2. 对话区（中间）

这是你跟 WorkBuddy 说话的地方。

- 顶部：任务标题、分享、历史记录等操作按钮
- 中间：消息列表，你和 WorkBuddy 的对话
- 底部：输入框，打字、粘贴图片、上传文件

### 3. 结果区（右边）

显示 WorkBuddy 干活的成果：

- **产物**：生成的文件（Word、Excel、PPT 等）
- **浏览器**：预览网页或应用
- **变更**：文件修改记录
- **工作空间文件**：当前文件夹里的文件

## 顶部操作按钮

从左到右：

| 按钮 | 干啥 |
| --- | --- |
| 搜索 | 在对话内容里搜关键词 |
| 分享 | 生成公开链接分享任务 |
| 历史 | 查看历史提问记录 |
| 详情面板 | 打开/关闭右侧结果区 |

## 输入框能干啥

不只是打字：

- 直接打字描述任务
- `Cmd/Ctrl + V` 粘贴截图
- 拖拽文件进来上传
- 点上传按钮选文件
- 用 `@` 引用文件或上下文
