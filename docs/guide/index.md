# 学习路线

## 先说结论

按需读，别按顺序。

WorkBuddy 是个工具，**用到啥学啥**最有效率。下面是我建议的路线，挑你需要的看。

## 路线一：第一次用（推荐大多数人）

1. [WorkBuddy 是什么](/start/01-what-is-workbuddy.md) - 搞明白这玩意干啥的
2. [下载安装](/start/02-installation.md) - 装上
3. [认识界面](/start/04-interface.md) - 知道每个区域干嘛的
4. [跑第一个任务](/start/03-first-task.md) - **最关键的一步**
5. [怎么创建任务](/start/05-create-task.md) - 学会描述需求
6. [对话和追问](/start/06-conversation.md) - 跟 AI 说话的艺术
7. [查看结果](/start/07-results.md) - 检查它干得对不对
8. [任务管理](/start/08-task-management.md) - 管理你的任务列表

## 路线二：想用高级功能

用熟了之后想玩花的：

1. [连接器（Connectors）](/features/01-connectors.md) - 连接外部服务
2. [专家（Experts）](/features/02-experts.md) - 专业角色加持
3. [技能（Skills）](/features/03-skills.md) - 可复用的任务流程
4. [自动化（Automations）](/features/04-automations.md) - 定时帮你干活
5. [MCP 配置](/features/05-mcp.md) - 接入更多外部工具
6. [记忆系统](/features/06-memory.md) - 让 AI 记住你
7. [文件访问](/features/07-file-access.md) - 操作本地文件
8. [分享功能](/features/08-sharing.md) - 分享你的成果

## 路线三：看实战案例

[实战案例库](/recipes/) - 照着别人的案例抄一遍，比看文档学得快。

## 我的建议

::: tip 过来人的话
用 WorkBuddy 最好的学法是**带着真实问题去用**。文档看十遍不如自己跑一次。
:::
