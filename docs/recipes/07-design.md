# 设计（Logo/海报/原型）

## 干啥的

需要 Logo、海报、Banner、图标、UI 原型？WorkBuddy 能直接
生成图片或者矢量设计稿。不用开 PS，不用找素材网站。

## 啥时候用

- 创业初期要个 Logo 先用着
- 活动要海报、社群要 Banner
- App/网页要做 UI 原型图
- 要做演示用的图标、插图
- 想看某种风格效果再决定要不要请设计师

## 怎么搞

**第一步：说清楚要啥。** 越具体越好：

```
帮我做个咖啡店的Logo：
- 风格：简约、文艺
- 元素：咖啡杯 + 店名"小日子"
- 颜色：暖棕色系
- 用途：印在杯子上和门头招牌
- 要矢量能放大
```

**第二步：让它先出几个方案。** 别只让它出一个，
让它「先给3个不同方向的方案看看」。挑一个方向再深入。

**第三步：迭代修改。** 比如「第二个方向不错，把杯子再简化点，
字体换个更圆润的」。一步步调到满意。

**第四步：要文件。** Logo、图标要矢量的就让它导出 SVG。
海报、Banner 要位图就 PNG/JPG。说明用途它会给对的格式。

## 看结果

- 图片生成后直接在对话里预览
- 文件会给下载链接
- 矢量文件能下下来再用 Figma / Illustrator 改

## 小技巧

::: tip
「找参考」比「凭空描述」效果好。看到喜欢的风格图，直接
发给 WorkBuddy 说「参考这个风格做」。AI 看图比听描述准。

Logo 这类要反复用的东西，一开始就要矢量格式（SVG），
不然放大糊了没法用。

颜色别描述「好看的蓝」，给个色值或者参考「类似星巴克那种绿」。
描述越具体，颜色越准。

文字较多的海报，先把文案定好再让它排版。边设计边改文案
效率很低。要让它自己写文案也行，但要先确认文案再让它出图。
:::
