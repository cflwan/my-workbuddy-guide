# 写邮件/周报

## 干啥的

要发邮件不知道怎么措辞？要发周报又懒得组织语言？
告诉 WorkBuddy 收件人、目的、要点，它帮你写好直接能发。

## 啥时候用

- 商务邮件：跟进客户、约会议、催付款
- 内部沟通：汇报进度、申请资源、跨部门协作
- 邮件版周报：给团队同步本周进展
- 回复难处理的邮件：拒绝、提意见、谈条件
- 模板邮件：欢迎信、通知、感谢信

## 怎么搞

**第一步：说场景和要点。** 比如：

```
帮我写封邮件：
- 收件人：合作方王总
- 目的：催他确认本周三的会议时间
- 语气：客气但要有压力感，不能太软
- 之前约过两次他都改时间了
```

**第二步：指定格式。** 要是公司有邮件模板或者你自己有偏好，
直接说：「开头用'王总您好'，结尾用我的名字'李雷'」。

**第三步：让它出几个版本。** 比如「给正式版和轻松版两个版本」，
挑一个改。或者出完一版直接说「再克制点」「更直接点」。

**第四步：复制走。** 满意了直接复制，粘贴到邮箱发出去。
要批量发就让它「写成模板，留出 [姓名]、[日期] 这种占位符」。

## 看结果

- 邮件正文直接在对话里
- 复制就能用
- 要模板版本会给你带占位符的文本

## 小技巧

::: tip
难处理的邮件最好把对方上一封原文给它：「这是他发来的，
帮我回复」。WorkBuddy 能读懂对方语气和诉求，回复更对症。

商务邮件别让它写太长，三段以内、每段不超过3行最好。
可以直接说「控制在150字以内」。

涉及谈判、提条件的邮件，告诉它你的底线。比如「我最多
给9折，但一开始报95折」，它会帮你铺垫。

周报邮件和单独的周报报告套路类似，但邮件版要更精简。
看 [01 写报告](./01-write-report.md) 学写完整版。
:::
