# 写周报/工作报告

## 干啥的

把本周干的事、数据、下周计划扔给 WorkBuddy，它给你整成一份结构清楚、
领导爱看的工作报告。不用自己憋半天开头怎么写。

## 啥时候用

- 每周五下午要交周报的时候
- 月底、季度末要写总结报告
- 项目结项要写汇报材料
- 述职、晋升材料需要整理成果

## 怎么搞

**第一步：把素材堆给它。** 别管格式，想到啥写啥。比如：

```
帮我写本周周报：
- 周一上线了支付模块，修了3个bug
- 周二周三对接银行接口，联调通过
- 周四做了一次性能测试，QPS从500提到1200
- 周五处理线上告警2次
- 下周计划：做对账系统，开始技术方案评审
```

**第二步：告诉它格式要求。** 比如公司有固定模板，就贴给它：

```
按这个格式输出：
1. 本周完成
2. 数据指标
3. 问题与风险
4. 下周计划
```

**第三步：让它润色。** 生成后可以说「把数据指标那块再具体点」
「语气正式一点，要给总监看的」，它会改。

**第四步：导出。** 满意了直接复制，或者让它存成文档。
要 Word/PDF 就说一声，能直接生成文件。

## 看结果

- 内容生成后在对话里就能看到全文
- 要文档文件的话，会在任务结果里给出下载链接
- 复制到公司模板里检查一遍数字对不对就行

## 小技巧

::: tip
素材越具体，报告越好。别只说「修了bug」，写「修复了订单状态
回滚的bug，影响约5%用户」。数字和影响范围是领导最爱看的。

要是本周没干啥大事，就把常规工作分类列出来，别空着。WorkBuddy
会帮你把小事也写出价值感，但别让它瞎编数据。

周报别太长，一页以内最好。可以让它「控制在500字以内」。
:::
