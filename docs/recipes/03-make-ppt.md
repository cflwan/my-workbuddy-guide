# 做 PPT

## 干啥的

给 WorkBuddy 一个主题或者一堆素材，它直接帮你出一整套 PPT，
有结构、有内容、有配图、有排版。下载下来打开就能讲。

## 啥时候用

- 临时要做汇报、分享、培训
- 有了内容素材，懒得自己排版
- 要做产品介绍、项目复盘
- 路演、答辩需要快速出片

## 怎么搞

**第一步：说主题和场景。** 比如：

```
帮我做个PPT，主题是「Q3产品迭代复盘」
- 受众：产品和设计团队，约20人
- 时长：15分钟
- 重点讲：本季度上线的3个功能、数据效果、下季度规划
```

**第二步：给素材（可选）。** 要是已经有文档、数据、图片，
一起丢给它：「这是相关资料，参考着做」。没有也没事，它会自己组织。

**第三步：指定风格。** 比如「简约商务风」「科技感深色」「活泼点」。
要参考某个已有 PPT 的风格，把那份上传给它看。

**第四步：生成。** WorkBuddy 会自动搭结构、写文案、配图、排版，
直接出 .pptx 文件。过程中可能问你一两个细节，答了就继续。

**第五步：调整。** 不满意就直说：「第3页内容太多删一半」
「整体换亮色系」「加一页讲风险」。改完重新下载。

## 看结果

- 任务结果里会给 .pptx 文件的下载链接
- 下载后用 PowerPoint / Keynote / WPS 打开
- 文字、图片都能再编辑，不是死的图片

## 小技巧

::: tip
一句话把受众和场合说清楚，效果差很多。「给老板汇报」和
「给新人培训」同个主题做出来的 PPT 完全不一样。

页数别贪多，一页一个重点最好。可以让它「控制在10页以内，
每页文字不超过50字」。

配图如果对不上号，告诉它「第4页那张图换掉，要XX感觉的」。
或者自己准备好图，让它插到指定页。

导出前一定下载下来本地打开看一眼，字体有时候会有偏差。
:::
