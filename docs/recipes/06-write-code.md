# 写代码/建网站

## 干啥的

说你要啥功能，WorkBuddy 直接帮你写代码、建项目、调试运行。
小到一段脚本，大到完整网站，都能搞。

## 啥时候用

- 想做个个人网站、落地页、小工具
- 需要一段脚本自动干某件事
- 看代码看不懂，让它解释
- 代码报错修不好，让它帮忙 debug
- 想快速搭个原型验证想法

## 怎么搞

**第一步：说清楚要啥。** 越具体越好：

```
帮我做个待办清单网页：
- 单页 HTML，不用框架
- 能添加、删除、勾选完成
- 数据存 localStorage，刷新不丢
- 简洁现代风格，浅色系
```

**第二步：它直接动手。** WorkBuddy 会创建文件、写代码。
过程中它会读项目结构、装依赖、改配置。你看着它干活就行。

**第三步：跑起来看。** 它会让你在本地预览，或者它自己起个
服务跑起来给你看效果。

**第四步：提改动。** 比如「按钮颜色换成蓝色」「加个清空
全部的功能」「手机上看着挤，调下响应式」。它改完再看。

**第五步：拿到代码。** 满意了，代码就在项目目录里，可以
复制走、推到 Git、或者让它帮你部署上线。

## 看结果

- 代码文件直接生成在指定目录
- 网页类可以直接在预览里看效果
- 报错它会自己修，修不好会告诉你卡在哪

## 小技巧

::: tip
需求写明白比啥都重要。把「想要啥样的」用大白话描述清楚，
包括功能、风格、数据存哪。模糊的需求会换来模糊的代码。

别一次要太多功能。先做核心功能跑通，再加细节。每加一块
就预览一次，有问题早发现。

报错别自己瞎改，直接把报错信息贴给 WorkBuddy，它修得比
你快。它能看完整的代码上下文。

要部署上线的话直接问「怎么把它发到公网」，它会给方案，
甚至能直接帮你部署到云上。
:::
