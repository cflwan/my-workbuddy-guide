# 深度研究

## 干啥的

给 WorkBuddy 一个研究问题，它会自己多轮搜索、对比多个来源、
整理成一份有结构的研究报告。比你一个个网页点过去高效多了。

## 啥时候用

- 做行业调研、市场分析
- 研究竞品、对比方案
- 写论文、做课题要查资料
- 买大件商品想对比评测
- 任何需要「查很多资料再总结」的事

## 怎么搞

**第一步：把问题问清楚。** 别只问一句话，给它背景和目标：

```
帮我研究一下国内主流的协作办公软件（飞书、企微、钉钉），
从功能、定价、适用团队规模三个维度对比，最后给个选型建议。
我们团队50人，偏产品研发。
```

**第二步：让它展开。** WorkBuddy 会自己拆解问题、分多轮去搜，
中间可能问你「要不要重点看某个方面」。让它继续就行。

**第三步：要来源。** 研究报告最怕瞎编。让它「列出每条结论的来源」，
或者「在引用后面标注链接」，方便你核对。

**第四步：让它整理。** 出完初版，可以要求：
「整理成表格对比」「按结论重要性排序」「生成一份PDF」。

## 看结果

- 研究报告直接在对话里展示
- 要文档版本可以导出 Word/PDF
- 要表格对比也能单独导出 Excel

## 小技巧

::: tip
问题越具体，研究越聚焦。别问「AI 行业怎么样」，问「2026 年
国内 AI 编程助手赛道，面向个人开发者的产品有哪些，各自
定价和差异化卖点」。后者出来的报告直接能用。

遇到关键结论，让它「展开讲讲这条，给出依据」。它能自己
往深里挖。

时效性强的内容（比如价格、最新政策），提醒它「优先用最近
半年内的信息」。它搜出来的东西会更新。

别一次性让它研究太宽的话题，拆成几个小问题分别问，
质量比一次问一大坨高。
:::
