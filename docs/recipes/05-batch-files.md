# 批量文件处理

## 干啥的

有几十上百个文件要统一改名、提取内容、转格式、汇总数据？
扔给 WorkBuddy，它写个脚本一次性搞定，不用你手动一个个点。

## 啥时候用

- 一堆照片要按「日期-地点」批量改名
- 几十份合同要提取里面的金额、日期汇总成表
- 一堆 Word 要批量转 PDF
- 一堆 CSV 要合并成一个大表
- 一堆文件按内容分类归档

## 怎么搞

**第一步：说明文件情况。** 比如：

```
我有个文件夹 /Users/me/contracts，里面有80个 Word 合同，
想从每份里提取合同编号、对方公司、合同金额、签订日期，
汇总到一个 Excel 里。
```

**第二步：让它先看一眼。** 让它先「看一下这个目录，
确认文件格式和数量对不对」。它会列出文件、读一份样本看看。

**第三步：确认方案。** WorkBuddy 会告诉你它打算怎么干，
比如「写个 Python 脚本读每个文件，提取这4个字段，存到
results.xlsx」。看着没问题就说「开始」。

**第四步：执行。** 它会跑脚本，过程中遇到异常会处理或问你。
跑完给你结果文件。

## 看结果

- 处理完会告诉你「成功多少个、失败多少个」
- 结果文件给下载链接，或者直接放在指定路径
- 失败的文件它会单独列出来，你可以看看是啥情况

## 小技巧

::: tip
先让它小范围试一下。比如「先处理前5个文件试试」，没问题
再让它处理全部。避免脚本有 bug 一次性把所有文件搞乱。

文件格式不统一很常见。让它「先看几份不同格式的样本」，
确认能覆盖各种情况再动手。

结果一定要核对几个样本。比如随便挑 3 个文件，对比它提取
的结果和原文一致不一致。脚本有时候会漏字段、识别错位。

要它把脚本也保存下来，下次类似任务直接复用改改就行。
:::
