# 数据分析

## 干啥的

扔一个 Excel 或 CSV 给 WorkBuddy，告诉它你想看啥，它帮你清洗、
算指标、找趋势、出结论，还能生成图表。省得你自己写公式。

## 啥时候用

- 月底要看销售/运营数据，懒得自己拉表
- 有个数据集想快速找出规律
- 要做数据周报、月报的图表
- 老板临时问「最近用户增长咋样」，要现算

## 怎么搞

**第一步：上传数据。** 把 Excel/CSV 文件拖进对话，或者告诉它
文件在哪个路径。WorkBuddy 会自己读。

**第二步：说要干啥。** 越具体越好。比如：

```
这是最近3个月的销售数据，帮我：
1. 算每个月的总销售额、订单数、客单价
2. 找出销售额Top5的品类
3. 看看有没有环比下降明显的
4. 画个趋势图
```

**第三步：它会自己动手。** WorkBuddy 会读表、看字段、清洗脏数据、
算你 要的指标、画图。中间有问题它会问你，比如「这列有空值，
要不要按 0 处理」。

**第四步：看结果提需求。** 出完一版，你可以说：
「再加个按地区拆分」「图改成柱状图」「导出一份带图表的报告」。

## 看结果

- 数据表格、图表直接在对话里显示
- 要 Excel 报告的话，会生成文件给下载链接
- 要图单独存的话，也能导出 PNG

## 小技巧

::: tip
第一次先让它「看一下这份数据，告诉我有哪些字段和大概情况」，
确认它读懂了再下具体分析任务。有时候字段名不直观，它猜错了
后面全乱。

数据量大别担心，WorkBuddy 能处理。但如果你只要其中一部分，
先说清楚「只看 8 月的数据」或「只看华东区」，会快很多。

让它出结论时加一句「用大白话说，别用术语」，报告更易读。
要给领导看就反着来，「写成正式报告风格」。
:::
